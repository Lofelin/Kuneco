# 偏好设置与快捷键

偏好设置提供聊天/代码字号（12–20 px）、减少动态效果、小时制、完整/相对时间和退出前运行任务提醒。语言保持原有账号同步；新增项目保存在当前设备的 `ui-preferences.json`，不随账号或环境同步。字号、发送方式与减少动态效果同步到独立聊天窗口。

“快捷键”位于设置侧栏“通知”下方。点击只读按键字段并按组合键即可保存；Delete/Backspace 清除，Escape 结束录制。重复或系统保留组合会报错且保留原设置。恢复默认会同时恢复发送方式和所有页面快捷键。

| 操作 | 默认（macOS；其他平台将 ⌘ 替换为 Ctrl） |
| --- | --- |
| 新建对话 | ⌘ N |
| 搜索当前对话 | ⌘ F |
| 聚焦聊天输入框 | ⌘ L |
| 停止当前回复 | ⌘ Shift Escape |
| 展开/收起侧栏 | ⌘ B |
| 偏好设置 / 快捷键设置 | ⌘ , / ⌘ Shift , |
| 下一个 / 上一个页签 | Control Tab / Control Shift Tab |
| 关闭当前页签 | ⌘ Shift W |
| 置顶/取消置顶 | ⌘ Shift P |
| 浏览器 / 自动化 / 运行时 | ⌘ Shift B / A / R |
| 控制台 | ⌘ ` |

页面快捷键在主窗口界面生效；弹窗、菜单、输入法组词和终端输入期间不抢占按键。固定/唯一页签不因关闭快捷键被移除。发送独立选择 Enter 或 ⌘/Ctrl+Enter，Shift+Enter 保留换行。

时间偏好不修改调度规则、系统时区或存储时间；自动化执行预览始终显示所选调度时区的完整时间，小时制跟随偏好。相对时间每 30 秒刷新，悬停时间可查看完整时间。

退出提醒默认开启，覆盖关闭主窗口与系统退出入口，列出正在执行的对话和自动化。取消、Escape 与关闭弹窗继续保留任务；确认后使用既有退出清理流程。未运行的计划任务不触发提醒。已有弹窗时保留当前操作并提示先关闭弹窗，避免叠加遮罩或意外取消授权中的任务。

验证：`npm run check`、`npm test`、`npm run test:desktop`。桌面验收使用正式 Kuneco 启动链路及临时账号数据，检查实际偏好页、主题与通知持久化和安全弹窗关闭；退出保护在实际对话和自动化同时运行时验证取消、Escape、已有弹窗保护和最终确认退出，详见 `test/e2e/legacy-coverage.md`。
