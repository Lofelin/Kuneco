# DeepSeek 工具与技能

DeepSeek 对话在当前环境容器中运行工具；模型请求、工具执行和后续结果回传均使用当前会话的环境和连接方式。没有代理到直连的隐式回退。

- `Skill`：从当前环境用户目录及当前项目的 `.codex/skills`、`.agents/skills`、`.claude/skills` 下读取一级技能目录中的 `SKILL.md`。项目同名技能覆盖用户技能；注册名称和说明，调用时才加载正文。技能文件须为 UTF-8，最大 64 KiB。名称支持字母、数字、横线及下划线。
- `Read` / `Write`：读取或写入当前项目内的 UTF-8 文件，解析真实路径，拒绝越出项目的路径。写入要求父目录已存在。
- `Bash`：在当前项目目录执行容器内 Bash，权限与当前容器用户一致；继承环境网络配置，遵守容器既有出口隔离。默认超时 120 秒，单次最多展示与回传 32000 字符，截断会明确标记。

Skill 活动完成表示技能指令已加载；技能要求的实际操作由后续工具活动分别展示，不将加载技能等同于整个任务完成。活动由执行器产生，包含参数、实际结果、耗时、退出码及失败/停止状态。没有工具调用的回复不会生成活动卡片。

每轮最多 24 次模型请求、64 次工具调用，工具顺序执行。调用前保存执行意图，调用后保存结果，再请求下一轮模型。断线或重启不自动重放命令；缺失结果会明确标记为未知。停止会取消请求并终止正在执行的命令进程组。历史保留工具请求、结果和思考字段，以满足 DeepSeek 多轮工具协议；编辑重发沿用现有分支历史语义，不重放之前的工具。

运行时源码及工具模块在每次发送前同步到当前容器。测试入口：

```sh
node --test test/unit/runtimes/deepseek*.test.mjs
```

真实验收需要已配置的 DeepSeek 账号和可用环境；单元测试的协议夹具不作为实机验收证据。
