# 对话交互增强

- DeepSeek 从真实 HTTP 状态及 Retry-After（秒或日期）提取恢复提示。429/503 的等待结束只开放手动重试，绝不自动发送；已经执行工具或压缩结果不确定时不提供重试。认证、余额、权限和参数错误分开提示。
- Markdown 代码块提供语言标签、单块复制反馈和行号开关。复制不包含行号或工具栏；流式更新保留代码选区、滚动和行号状态。搜索排除工具栏文字。
- 图片画廊仅收集当前对话及当前草稿图片，支持前后切换、光标锚点缩放、拖动、复位和键盘操作。切换账号、环境或对话关闭画廊，异步读取结果不得串到新对话。
- Claude 对话采用 SDK 默认权限模式和真实 canUseTool 回调，支持单次允许或拒绝；批准不代表执行成功，最终结果来自运行时活动。请求取消自动拒绝待定授权。Codex exec 与 DeepSeek 未接同等交互协议，不显示伪授权按钮。
- 固定对话支持拖动或 Alt+方向键排序，普通方向键/Home/End 导航。排序保存在本机，按账号、环境隔离；普通未固定对话仍按时间排序。

验收：真实 DeepSeek 生成代码块后复制/行号通过；两张真实图片切换、缩放、拖动、复位及全局遮罩通过；固定对话键盘排序与重启恢复通过。授权回调隔离与取消、Retry-After 与工具执行后禁止重放通过协议级测试。Claude 当前未登录，原生授权端到端验收待登录后继续；没有人为制造线上限流，线上 429/503 尚未自然触发验收。
