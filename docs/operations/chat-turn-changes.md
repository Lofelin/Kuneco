# 本轮文件变更汇总

输入框上方显示当前对话最近一轮执行确认修改的文件数量及净增删行数。点击直接打开窗口级产物侧栏；侧栏列出本轮文件，点击文件展开并定位差异，仍可手动折叠，统一/左右对照复用既有差异组件。

## 数据边界

- 主进程为每次执行生成独立标识，记录账号、环境、对话；已完成工具活动中的真实变更回执带该执行标识。IPC 和汇总均检查作用域。
- 不扫描工作区 Git 状态，不按时间猜测归属，不把其他会话或旧历史产物算入本轮。新执行开始后清空上一轮入口；结束后保留本轮结果，重启仍能读取。
- 同文件多次写入仅在快照连续时计算首尾净差异。快照不连续、二进制、缺失/截断差异、多次仅有 patch 无法合并，或超出精确比较预算时，显示“无法统计”。有任一文件无法统计时，总计也不伪造数字。
- 只计运行时明确报告并确认完成的修改；没有文件变更回执的 Shell 副作用不推测成文件修改。失败工具不计入，失败或停止前已确认完成的修改仍保留。
- 不自动重发执行；未知历史回执没有执行标识时，仍可在历史产物中查看，但不会猜测为本轮。

## 持续入口与差异侧栏

右上角会话三点菜单顶部提供持续的“变更”入口，汇总当前账号、环境、对话的已归属执行回执。输入框上方仍是最近一轮；新执行清除该轮提示不删除历史回执。会话总计仅合并连续快照，存在缺失或不连续差异时显示无法统计，不读取其他会话或工作区 Git 状态。

侧栏支持文件下拉与范围选择（当前对话、最近一轮、更早轮次），直接展开统一/左右差异，不再通过多层产物折叠查找。所选文件、范围与模式随当前对话保存。
