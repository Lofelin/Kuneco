# 对话输入、文档与独立窗口

## 功能与真实来源

- 输入法确认：主输入、文件/技能建议选择、消息编辑和独立窗口共享组合输入保护。确认候选词的 Enter 不提交；keyup 后的下一次 Enter 正常处理，没有固定 500ms 冷却。
- 文档附件：当前支持图片输入的 DeepSeek/Codex 对话可添加 UTF-8 文本、代码、可提取文本的 PDF。原文件最大 5 MiB，最多 10 份，提取内容合计最多 40000 字符。卡片显示真实名称、大小、类型与读取状态。损坏、加密、二进制或无文本的 PDF 报错，不伪造 OCR。
- 文档在本机读取，内容随当前账号、环境、对话的草稿和待发送记录保存，发送时作为明确标记的不可信文件内容进入运行时。不会把宿主路径当作容器路径；`@` 选择明确标记为尚未读取的当前环境路径引用。
- Mermaid 使用锁定版本的本地依赖，无 CDN。提供图表/源码切换、错误状态和净化 SVG 导出，拒绝外部资源与配置覆盖。图片隔离预览不执行模型输出中的脚本。
- Codex 推理强度来自当前环境 app-server `model/list` 的 `supportedReasoningEfforts`，按对话保存，发送前重新校验，并通过 `turn/start.effort` 传递；未选择则保留运行时默认。DeepSeek 保留真实 thinking 开关，不推测不存在的分级；Claude 尚未完成登录，不显示伪造能力。
- 聊天三点菜单提供独立窗口。主页面是唯一状态写入者，子窗口只有限定账号/环境/对话的编辑、发送、停止与聚焦通道。修订版本过期会拒绝覆盖；后台对话可发送，其他对话输入不被切换。未知执行结果保留恢复记录，不自动重发。主窗口关闭时子窗口一并关闭。
- 产物仍是窗口级侧栏；修复盒模型宽度溢出，标题/分隔线贴齐边缘，空状态整体居中，保留调宽、手动折叠与过渡。窄视口显示右侧抽屉。
