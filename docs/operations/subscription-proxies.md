# 订阅代理与环境隔离

代理弹窗支持 HTTPS 订阅链接、Clash YAML/JSON 文件、VLESS/Hysteria2/SS URI 与 Base64 内容。导入后显示全部节点；不兼容或关闭 TLS 的节点禁用并显示原因。选择节点只生成草稿，点击保存并连接后才应用到当前环境。

使用固定版本 Mihomo，仅运行所选出口节点及可选的单个固定 TLS VLESS 前置节点，无自动切换、DIRECT 回退、系统代理或 TUN。内核配置与凭据通过独立临时目录的 0600 文件传递，停止后删除；容器使用其自身网关内核，不共享其他环境连接。订阅规则、代理组、监听配置不会导入。订阅 URL 不写入连接配置或日志，仅所选节点随当前账号/环境加密保存。

```sh
npm run proxy:install-mihomo
node scripts/setup/install-mihomo.mjs linux_arm64
```

安装脚本下载官方固定版本并校验固定 SHA-256；其他受支持平台使用 `darwin_amd64`、`linux_amd64` 参数。宿主及对应容器架构均需安装。原生 HTTP/HTTPS/SOCKS5 不依赖该内核。

仅订阅节点的服务器域名通过加密 DNS 引导解析，TLS 名称保留；ECH 参数通过 HTTPS DNS 记录取得后固定传入内核，不使用系统 DNS 查询目标域名。订阅下载只允许标准 HTTPS，拒绝私网入口、超限内容与危险跳转。

出口仍先核验再开放转发，同一账号、环境和节点固定已核验 IP；出口变化会锁定，不能通过换节点或清除记录自动接受。动态家宽会因真实出口变化触发此保护。导入不会修改其他环境或既有 IPRoyal 配置。

Hysteria2 若同时提供 SHA-256 证书指纹，则去掉跳过验证标记，交由内核严格匹配该指纹；没有可信指纹时强制执行系统证书链和 SNI 校验，证书错误时连接失败，应用不会自行信任首次看到的证书。节点可解析不代表实际可连接，SS 中转条件、节点套餐与上游连通性需单独实测。


## 固定前置节点与真实连通性

导入列表中选择 Hysteria2 或 SS 后，可在“前置节点”选择同批订阅中的一个 TLS VLESS 节点。仅保存两条经过白名单校验的节点，不导入订阅代理组或规则；不接受嵌套链、DIRECT、跨环境引用。前置节点凭据与出口节点一起加密保存，链路变化会改变节点身份；已保存配置的出口记录仍跟随稳定配置 ID，编辑节点或前置不能重置出口记录。出口核验检查最终落地 IP。

2026-10-21 隔离实测：提供的两条订阅日本 Hy2 经固定 VLESS 前置均核验为 210.231.180.79；新加坡 Hy2 经前置核验为 67.159.52.205。相同 Hy2 直连在 QUIC 握手阶段超时。第二条订阅 AT&T SS 直连及固定 VLESS 前置均核验为 72.159.77.15，本机与隔离容器网关通过。T-mobile SS 在相同服务器、加密方式和凭据下，直连及香港/美国/日本前置均失败，尚未恢复，不能认为所有供应商节点均可用。

## 每个环境保存多个代理配置

“已保存代理”支持按 IPRoyal、苏菲家宽、其他代理筛选。新增配置可以只保存而不切断当前代理；选择配置后点击“切换并核验”，仅切换当前账号当前环境的代理。切换先关闭旧转发，核验所选配置原有的固定出口；失败保持锁定，不回退其他配置或直连。

配置列表使用系统凭据加密，按账号和环境散列分文件保存在本设备 userData/proxy-profiles/。每个环境最多 50 条。既有代理首次显示为“现有代理”，读取列表不改写原代理；保存其他配置时将原代理纳入列表。新配置具有稳定 UUID，固定出口记录同时绑定账号、环境与配置；旧配置保留原来的身份与固定出口记录。容器环境不互相共享配置。列表属于本设备；账号本机环境的当前活动配置仍沿用既有账号同步机制。

德国 Hy2 订阅虽含 skip-cert-verify:true，实际可通过系统证书链和 SNI 验证；经固定 VLESS 前置实测出口 152.53.143.195。导入 Hy2 时不执行供应商的跳过验证请求，而是规范化为严格验证并提示；指纹格式错误仍拒绝导入。
