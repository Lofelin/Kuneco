# 统一记忆服务

从「智能 → 记忆库」进入。Claude Code、Codex、DeepSeek 对话和现有定时对话使用同一套服务，按账号与环境隔离，项目专用记忆另外按项目路径过滤。控制台中自行启动的 CLI 不会自动接入。

## 写入与提取

默认开启自动提取，可在「设置 → 智能 → 记忆」关闭。只有成功完成且未取消的对话才排入持久化提取队列。提取是独立请求，不恢复原会话，不重复用户任务。当前提取器使用完成本轮对话的运行时和模型，并保持原连接方式及代理门禁。后台每次处理一个任务；前台聊天、自动化执行或账号/环境切换会暂停提取，回到原范围后恢复。

提取输入最多保留本轮用户文本 12000 字符和助手文本 6000 字符，最多返回 8 条记忆。每条必须引用用户原文的逐字证据；助手输出仅作为上下文，不能独自成为事实证据。忽略临时提问、假设、未验证的模型执行结论及常见凭据格式。服务另外拦截仅含提问或答复格式指令的证据，避免把召回问句合并为事实来源。提取失败不会影响已完成回复，不自动重发模型请求，进度与失败原因写入当前环境日志，可从「设置 → 记忆」重试失败提取。记忆库不再展示提取记录。

Claude 提取关闭内置工具、MCP、插件、文件设置和会话持久化；DeepSeek 使用不提供工具、无历史读写的独立 API 操作；Codex 使用独立临时目录、临时会话、只读 sandbox、忽略用户配置/规则，关闭 shell、搜索、浏览器、插件等能力，检测到工具活动就中止。Codex 的事件检测发生在活动报告时，因此不将它描述为平台级“全部工具绝对不可启动”；只读 sandbox 与工具配置共同限制提取行为。

## 去重、冲突与来源

每条记忆包含类型、稳定主题键、关键词、来源和完整修订记录。来源记录对话/自动化 ID、本轮 ID、运行时、模型、时间和用户原文摘录。

- 相同正文合并来源，不创建重复条目；同一主题的自动记忆可更新原条目并保留旧版本。
- 用户手动维护的内容、已停用条目，以及提取期间出现新修订的条目受到保护；自动结果进入「待处理冲突」，由页面选择「采用新约定」或「保留现有」。采用前再次检查原条目的修订版本。
- 移除是可恢复的逻辑移除，来源与修订不丢失；在「包含已移除」中查看并恢复。已移除主题不因任务重放恢复。
- 重复排队使用账号、环境和本轮 ID 组成幂等键。进程中断时未完成的提取在下次启动恢复，重复完成不会重复写入。

## 读取与手动管理

请求前使用中英文词、中文双字词及提取器给出的相关关键词评分，结合标题权重和轻量新近度进行召回；这是本机词项相关性检索，未使用向量嵌入服务。只读取启用、当前有效、项目范围匹配的记忆，默认最多 8 条、JSON 上下文不超过 6000 字符；在「设置 → 记忆」可关闭请求前召回，或选择 4/8/12 条、3000/6000/12000 字符。设置按当前账号及环境保存，提取去重仍读取已有记忆，不受请求前召回开关影响。每条保留完整正文，超出预算时跳过，不截断。最多附带 3 条未直接匹配的通用偏好；「始终读取」的条目优先计入预算。

记忆库使用紧凑搜索、分类计数、带选项计数的类型/来源/状态级联筛选及排序，列表复用全局表格的扁平布局；“全部”包含已移除条目，不包含已处理的内部冲突候选。筛选子菜单向左展开，菜单显示已选值，列表上方的条件标签可逐项清除。保留手动编辑、启用/停用、始终读取、查看来源与修订、处理冲突和恢复；不提供新增按钮。手动保存检查修订号，拒绝覆盖已经发生的新修订。

召回内容作为参考上下文加入本轮请求，不修改运行时原生记忆或项目规则文件。旧请求里已发送的历史内容不会被清除，当前任务的明确要求优先。

## 后端持久化与本机缓存

在“设置 → 智能 → 记忆 → 存储位置”选择“本机设备 / 云端同步”，默认本机设备。选择保存在本机并按账号/环境隔离，已有云端缓存也不会自动启用同步。本机模式使用 `memory-local.bin`，记忆读写、提取队列与召回不调用记忆后端接口。模型提取和回答仍使用所选模型服务；此选项不控制聊天记录同步。

云端同步模式的权威数据保存于 Kuneco 后端 PostgreSQL 的 `memory_states` 表，按登录账号、环境标识隔离，包含条目、来源修订、设置、提取队列与迁移标记。后端沿用 AES-GCM 加密密钥；修订号和事务锁防止旧快照覆盖新状态。相同账号和环境标识可以跨设备共享。

Kuneco 本机的 `memory-cache.bin` 保存已同步缓存和离线待上传轮次，使用系统加密能力保护、0600 文件权限及原子替换。请求发送前刷新当前范围，后台空闲时也会轮询同步。断网时读取最近缓存，新轮次持久排队后等待上传；手动修改和设置修改需要后端确认。

原 `memory-library.bin` 保留为迁移备份，不改写；首次只复制到本机记忆库。两种存储的数据独立保留，切换不会自动上传或删除。云端模式下可另点“上传本机记忆”，按范围幂等上传记忆、来源、修订与提取任务；后端已有相同 ID 时以后端为准，其他账号的数据不会上传到当前账号。迁移标记防止重复导入。

提取器通过后端版本竞争领取 120 秒租约，过期后可恢复；旧执行器不能提交或重置已被其他设备重新领取的任务。模型调用仍由本机可用运行时执行。

每个范围最多 1000 条未移除记忆，标题最多 80 字、单条正文最多 4000 字。后端快照最大 32 MiB，每次召回另受条数与字符预算限制。加密、写入或验证失败时保留上次成功状态；损坏文件不会自动覆盖。

## 分层与语义召回

记忆库的「分层」可查看来源证据、原子记忆、场景摘要与稳定偏好。摘要直接组合当前有效成员，不推断个人画像；修改、停用、移除成员后即时生效。

设置 → 智能 → 记忆 → 本机语义召回可准备多语言模型（约 135 MB 静态下载）。不会自动下载模型；未准备或超时时使用关键词召回，并显示原因。准备后向量在本机生成，查询和记忆不会上传至向量服务。提取和批量去重仍使用原会话运行时及模型，会使用模型额度。

默认存储仍为本机设备。混合召回与分层不会开启云端同步；选择云端也不会自动上传已有本机记忆。

## 后台历史提取的使用

点击「提取历史记忆」后立即返回，不必停留在设置页。设置行显示扫描或完成轮数；任务结束通过全局通知报告成功、失败、取消数量。通知遵循「设置 → 通知」的操作反馈与系统通知偏好。关闭设置页不影响处理，正常退出并重新启动后任务可恢复；关闭整个应用时不继续运行模型。

在其它账号、环境或另一存储模式下不会继续处理原任务，返回原范围后恢复。本机模式仍不上传记忆；任务清单本身始终保存在本机。失败轮次可在记忆设置重试。
