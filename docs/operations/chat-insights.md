# 对话产物、用量与上下文管理

对话标题旁的“产物与用量”打开当前账号、当前环境、当前对话的侧栏。宽窗口可拖动分隔条（键盘方向键也可调整，双击复位），窄窗口改为覆盖式侧栏。各分组及文件差异可手动折叠，状态按账号、环境、会话保存。

## 真实产物

产物来自运行时成功写入文件的活动事件；历史活动也可恢复索引。当前支持 DeepSeek Write、Claude Edit/Write 快照以及 Codex file change 事件。Bash 任意文件修改不自动猜测为产物，普通回复代码块也不冒充文件。

同一路径按成功事件记录版本。已有文本快照可预览生成时版本；“读取当前文件”从原环境读取当前内容，不代表历史版本。文本、Markdown、图片与 HTML 支持预览；二进制和超过 2 MiB 的当前文件显示明确不支持。快照采集仍限 64 KiB。

HTML 通过独立随机地址及 sandbox iframe 渲染，没有 Node、主窗口或 workspace API 权限；允许内部脚本、样式，禁止外部资源、网络连接、表单、弹窗和子框架。地址只在原账号与原环境有效。预览不是发布网站。

## 用量口径

会话累计、最近回复输入/输出及缓存命中来自真实返回。压缩摘要调用单独计入累计，不替代普通对话的最近输入。历史仅保存总数时，新增明细显示未知。最近请求输入不是精确的当前上下文占用，模型容量只有运行时返回才展示；没有容量不生成百分比。压缩后、下一轮之前不沿用旧上下文输入值。

## 压缩与恢复

- Codex：通过当前环境 app-server 的 thread/compact/start 触发，收到 contextCompaction 完成事件才标成功；运行时不返回摘要正文或恢复接口时明确说明。
- DeepSeek：当前模型单次无工具摘要，按完整 user 回合保留最近两轮及工具结果；先备份原历史，验证摘要完整且历史未变化，再原子替换。原始聊天展示不删除。摘要失败或取消不替换历史。
- DeepSeek 恢复：校验压缩后历史 hash，仅在没有后续消息时恢复，防止覆盖新消息。备份保留在所属环境运行时目录。
- 同一对话发送和压缩互斥；不同对话独立。停止和账号/环境切换取消对应请求，不自动重试有副作用操作。
- Claude 当前因官方登录受阻，真实执行及压缩接入暂缓，不显示虚假的可用压缩入口。

目前提供显式手动压缩，不自动在后台触发付费摘要。
